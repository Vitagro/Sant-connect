💳 CMI — Centre Monétique Interbancaire

Paiement sécurisé 3D Secure — Visa, Mastercard, CIH Card, Attijariwafa, BMCE...

Vous serez redirigé vers la page sécurisée CMI. Votre banque vous enverra un code OTP par SMS.

🔵 PayZone — Paiement en ligne Maroc

Passerelle de paiement certifiée PCI-DSS. Compatible toutes cartes bancaires marocaines.

🏦 Virement bancaire — Référence unique

Référence de virement :
IBAN : MA64 0000 0000 0000 0000 0000 00
SWIFT : BCMAMAMC

Valide 72h — Mentionner la référence dans le motif

🟢 edahabia — Algérie Poste

Carte de paiement électronique Algérie Poste. Acceptée pour les patients algériens.

🔴 Wafacash — Paiement espèces via agence

Paiement possible dans toutes les agences Wafacash au Maroc. Code de paiement généré après confirmation.

💵 Paiement en espèces — À la réception

Présentez ce document à la réception. Paiement en MAD uniquement.

Mises à jour prévues

Roadmap SantéConnect v3

v1.0 — Lancé
🏥 Plateforme de base
Médecin, Patient, Pharmacie, Laboratoire. Ordonnances + Notifications WhatsApp. Trilangue FR/AR/EN.
✅ Livré
v2.0 — Livré
🗄️ Intégration Supabase + Vercel
Base de données PostgreSQL, RLS sécurité, API Node.js, déploiement Vercel, variables d'environnement.
✅ Livré🔒 Sécurité
v3.0 — En cours
🦷 Toutes spécialités + Paiement + Assurances
25 spécialités médicales (dentiste, ophtalmo, kiné, psy...). 6 méthodes de paiement (CMI, Virement, Wafacash...). 12 compagnies d'assurances marocaines.
🔵 Actuel🔒 CNDP
v3.1 — Prévu T2 2025
📱 Application Mobile (React Native)
App Android & iOS avec Expo. Notifications push. Scan d'ordonnance. Biométrie (Touch ID / Face ID). Mode hors-ligne.
📋 Planifié
v3.2 — Prévu T3 2025
🤖 IA Médicale (Aide à la prescription)
Détection automatique d'interactions médicamenteuses. Vérification des contre-indications selon les allergies. Suggestion de doses selon poids/âge.
📋 Planifié⚠️ Validation médicale requise
v4.0 — Prévu T4 2025
🇲🇦 Migration Hébergement National Maroc
Transfert complet vers serveurs Inwi/Orange/IAM. Données 100% sur territoire marocain. Conformité totale CNDP Art. 43-46. CMI Production. Audit pentest externe.
📋 Planifié🔒 Souveraineté données
v4.1 — Prévu 2026
🏥 Téléconsultation (avec agrément)
Consultation vidéo sécurisée entre médecin et patient. Signature numérique qualifiée. Intégration Dossier Médical Partagé (DMP). Agrément Ministère de la Santé Maroc.
📋 Planifié⚠️ Agrément requis
